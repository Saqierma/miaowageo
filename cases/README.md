## 关于匿名

标着「已匿名」的四份，是**真实用户提交的中小外贸站**。

他们只是来用了一下免费工具，没有同意成为案例。线上的报告页是
`noindex` + 不可猜测链接保护的——把域名写进公开仓库，等于我们自己把那层保护掀了。
而这与工具页上「不注册、不留邮箱、不留手机号」的承诺是同一件事。

所以域名被整体替换成占位符，**其余一个字都没改**：所有观测结论、限制说明、
判定结果都是原样的真实数据。教学价值在**模式**，不在**是谁**。

匿名代号刻意不带行业描述（不写「某电子元件厂商」）——从域名反推行业本身
就是一条识别线索。

另外四份是公开的大型 B2B 平台与本工具自己的站点，由我们主动测试，直接具名。

## 怎么读这些报告

每份案例都有两部分：

- **`NN-xxx.md`** —— 汇总、最要紧的几条观测、这个案例说明了什么
- **`raw/NN-xxx.json`** —— 完整的原始检查结果，每项都带 `observation` 与 `limitation`

原始 JSON 的字段含义见项目 [README 第四节](../README.md#四它到底检查什么)，
每一项的大白话解释见 [`src/explain.mjs`](../src/explain.mjs)。

> **注意日期。** 部分早期报告跑在 `metadata` 组（8 项页面元信息检查）加入之前，
> 计分项总数是 22 而不是 26。报告表格里的「计分项」一栏写的是那次检测的实际项数。
